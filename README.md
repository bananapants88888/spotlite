# Banana Music

Download, play and sync your music on Windows and iPhone.

**Get it:** open [Releases](../../releases/latest), download `Banana-Music-Setup-….exe` and run it.
Windows says it's an unrecognized app (it isn't code-signed): click **More info**, then **Run anyway**.

The app updates itself from here: press **Refresh** on its iPhone chip (or **Update the PC app** in
its Settings). This repo holds the finished downloads only.

# Spotlite

Download, play and sync your music on Windows and iPhone.

**Get it:** open [Releases](../../releases/latest), download `Spotlite-Setup-….exe` and run it.
Windows says it's an unrecognized app (it isn't code-signed): click **More info**, then **Run anyway**.

The app updates itself from here: press **Update** on its iPhone chip. It gives the iPhone app
7 more days, installs its newest version when there is one, updates the PC app, then syncs your
songs, playlists and settings. This repo holds the finished downloads only.
